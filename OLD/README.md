# 🎵 Birthday WinAmp — Setup Guide

מתנת יומולדת: נגן מוזיקה בסגנון WinAmp 2.95 / Windows 95 עם הפלייליסט של ספוטיפיי.

## העלאה ל-GitHub Pages

```bash
git init
git add .
git commit -m "🎂 Birthday gift"
git branch -M main
git remote add origin https://github.com/alontayar/luiza.git

```

האתר: **https://alontayar.github.io/luiza/**

## שימוש (מהצד של הנמען)

1. כנס לאתר
2. קרא ברכת יומולדת → לחץ **OK**
3. לחץ **⏏ CONNECT** → התחבר עם Spotify
4. הפלייליסט נטען — זהו!

> ניגון מלא דורש **Spotify Premium**. עם חינמי — 30 שניות לשיר.

## קיצורי מקלדת

| מקש | פעולה |
|-----|--------|
| `Space` | Play / Pause |
| `→` | שיר הבא |
| `←` | שיר קודם |
| `S` | Shuffle |
| `R` | Repeat |
